# E-Commerce Website – Manual Testing Project

## Project Overview

This project demonstrates manual testing of an E-Commerce website. 
The testing covered major user workflows including login, product listing,
product sorting, shopping cart, checkout, order placement, and order completion.

## Testing Scope

- Login
- Product Listing
- Product Sorting
- Shopping Cart
- Checkout
- Order Placement
- Order Completion
- Order PDF Generation

## Testing Performed

- Functional Testing
- Positive Testing
- Negative Testing
- Validation Testing
- End-to-End Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- Retesting

## Defects Identified

### BUG-001 – Last Name field does not accept text input
The Last Name field does not accept valid text input during checkout.

### BUG-002 – Product image is not displayed in the cart
Product name, price and quantity are displayed correctly, but the product image is not displayed.

### BUG-003 – Postal Code accepts invalid alphabetic input
The Postal Code field accepts alphabetic input such as `abc` and allows the user to continue.
